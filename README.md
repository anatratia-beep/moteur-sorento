# moteur-sorento

Modèle 3D interactif du moteur Kia Sorento 2014 (Three.js).

- `Moteur-Sorento-2014-3D.html` : version originale (charge Three.js et les polices depuis Internet).
- `Moteur-Sorento-2014-3D-offline.html` : **version 100 % hors ligne**, un seul fichier, générée automatiquement par GitHub Actions (Three.js 0.147.0 et polices Barlow intégrés).
